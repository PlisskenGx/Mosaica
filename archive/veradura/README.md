# Veradura historical reference

This archive preserves the Veradura material that remains useful to Mosaica's
development history and physical validation.

- `reference/` contains the human-edited benchmark project. Its legacy project
  schema identifier is retained for compatibility, and `../mark.svg` remains
  its portable source reference.
- `mark.svg` is the source artwork associated with that benchmark.
- `viability/fabricate_phase1_1_review/` is the authoritative V4 Rounded
  physical-viability baseline: its manifest records the fabrication profile,
  geometry signatures, and mesh validation, while its STL bodies preserve the
  known review geometry.

Current production fabrication architecture and code live in Mosaica
Fabricate. The files here are reference evidence, not runtime dependencies.
